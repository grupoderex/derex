================================================================================
  ENDPOINTS DE PRODUCCIÓN A CONSULTAR
================================================================================

Reemplaza https://preprod-api.javer.com.mx con la base URL y [PROD_ID] con el id del proyecto en prod.

1. PROYECTO COMPLETO (incluye credit_types, hasPropertyWithEdgeCertification)
  GET https://preprod-api.javer.com.mx/proyectos/id/[PROD_ID]

2. PROPIEDADES del proyecto (lista con precios base)
  GET https://preprod-api.javer.com.mx/propiedades/properties_search?project=[PROD_ID]

3. PROPIEDAD INDIVIDUAL completa (con blueprints, imágenes, precios)
  GET https://preprod-api.javer.com.mx/propiedades/id/[PROP_ID]

4. AMENIDADES TEXTO del proyecto
  GET https://preprod-api.javer.com.mx/amenidades/get_all/[PROD_ID]
   → Filtrar los que tienen "name" (texto), campo label/icon

5. AMENIDADES IMAGEN del proyecto
  GET https://preprod-api.javer.com.mx/amenidades/get_all/[PROD_ID]
   → Filtrar los que tienen "name" = null (solo imagen/url)

6. PROMOCIONES del proyecto
  GET https://preprod-api.javer.com.mx/project-promotions/get-by-project/[PROD_ID]

7. TIPOS DE CRÉDITO disponibles (catálogo global)
  GET https://preprod-api.javer.com.mx/cat-credit-type/get-by-filters

8. IMÁGENES de propiedad (si no vienen en /propiedades/id/:id)
  GET https://preprod-api.javer.com.mx/imagenes-propiedades/get-by-property/[PROP_ID]

9. PLANOS / BLUEPRINTS de propiedad
  GET https://preprod-api.javer.com.mx/planos/get-by-property/[PROP_ID]

10. PRECIOS de propiedad
    GET https://preprod-api.javer.com.mx/precios/get-by-property/[PROP_ID]

11. TÍTULOS DE SECCIONES DEL PROYECTO (meta CMS)
  GET https://preprod-api.javer.com.mx/meta/project_[PROD_ID]
  → En local se debe guardar como section=project_[LOCAL_ID] en tabla meta

================================================================================
  ERRORES COMUNES Y SOLUCIONES
================================================================================

ERROR: Incorrect datetime value: '0000-00-00 00:00:00'
  → Causa: La columna update_at rechaza fechas cero
  → Solución: Siempre incluir created_at=NOW(), update_at=NOW() en el INSERT
              de project_property_images

ERROR: Cannot add or update a child row: foreign key constraint fails
  → Causa: El id_property no existe en la tabla property todavía
  → Solución: Insertar primero las propiedades (property), luego sus relaciones

ERROR: Duplicate entry 'X' for key 'PRIMARY'
  → Causa: El registro ya existe
  → Solución: Usar ON DUPLICATE KEY UPDATE en vez de INSERT simple

ERROR: Edge logo no aparece en ProjectCard
  → Causa: No hay ninguna property con isEdgeCertified=1 para ese proyecto
  → Solución: Asegurarse de que al menos 1 propiedad tenga isEdgeCertified=1
              en la tabla property (la consulta es en project.sql.js)

ERROR: Credit badges no aparecen
  → Causa: Tabla project_credits vacía para ese proyecto
  → Solución: Insertar los tipos de crédito en project_credits

ERROR: Amenidades de texto no aparecen (solo círculos con imágenes)
  → Causa: amenity_property solo tiene registros con name=NULL (solo imagen)
  → Solución: Insertar amenidades con name IS NOT NULL (texto + ícono)

================================================================================
  NOTAS ADICIONALES
================================================================================

- El mapper de proyecto ID que usamos: local project 25 = preprod project 140
  Verificado el 2025 en la tabla de la sección de estado (arriba).

- Las imágenes en project_property_images y project_property_blueprints 
  usan URLs absolutas que apuntan al servidor de producción/uploads.
  En local el navegador cargará esas imágenes directamente desde prod (OK).

- Los campos JSON (como interest_area, amenities en project) pueden contener
  datos de áreas de interés distintos de amenity_property. Son dos fuentes 
  separadas de datos, NO confundir:
    · project.interest_area  → tarjetas en "Zona de interés"  
    · amenity_property       → íconos de amenidades del proyecto

- El frontend hace SSR para páginas de propiedad individual. Si los cambios
  no se ven en el navegador, hacer hard-refresh (Ctrl+Shift+R) o reiniciar
  el servidor Next.js.
